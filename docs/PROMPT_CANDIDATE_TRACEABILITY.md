# Casual prompt candidate traceability

**Static mapping only.** The active [Builder v7.4](../prompts/casual/builder/stable/MTG_Deck_Builder_v7.4_full.md) and [Tester v3.4.2](../prompts/casual/tester/MTG_Deck_Tester_v3.4.2_full.md) remain unchanged. The [compact Builder](../prompts/casual/builder/experimental/MTG_Deck_Builder_compact_candidate.md) and [compact Tester](../prompts/casual/tester/experimental/MTG_Deck_Tester_compact_candidate.md) are experimental. Candidate sections below are stable anchors by section number, not overrides. “Case” means a planned AI probe, not a passed test; fixtures exercise only the indicated deterministic layer. “Review” means text checked against the baseline with no executable comparison yet.

The Builder baseline has a front execution map, an inventory override and two synergy layers above v6.14. Preserve the specific independent-inventory rule, consolidate the overlapping checks, and keep displayed-list reconstruction distinct from tool validation. The Tester baseline explicitly subordinates v2.5 where that version makes STANDARD simulations/mulligans, selected-spell analysis or completion broader than A–D3. Keep useful historical event definitions as conditional instructions and keep the current D2/D3 gates mandatory. Historical text remains in the unchanged baselines. The existing [agent entry point](../AGENTS.md), [Gateway contract](AGENT_RESULT_CONTRACT_V1.md), [role discovery](CARD_SEARCH.md) and [shared Validator handoff](../prompts/casual/SHARED_PYTHON_VALIDATOR_HANDOFF.md) delimit what each tool can establish. No new runtime entry point, service or mandatory orchestration is introduced.

Retained duplication is intentional where independent evidence matters: reading card text is separate from heuristic discovery; an exact displayed list is separate from the draft and tool input; aggregate ownership is separate from format legality; the Tester must reconcile independently even if the Builder ran a Validator. The single workflow removes historical resolution, repeated source scans and redundant routine computations. See the [same-host pilot](../examples/prompt_benchmark/pilot/README.md) for two scoped comparisons. General behavior remains unverified.
