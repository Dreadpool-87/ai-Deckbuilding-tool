# CI maintenance

The public preview runs offline regression suites on Python 3.12 and 3.13. See the [CPython version lifecycle](https://devguide.python.org/versions/) before changing the matrix. Run the root, Forge and Commander Spellbook suites on a candidate version before adding it. Run the workflow syntax and policy checks with `python scripts/check_workflows.py` after installing the CI-only PyYAML version listed in [the regression workflow](../.github/workflows/python-tests.yml).

Every Action in this repository is pinned to a full upstream commit SHA, with the corresponding release tag in a comment. To update an Action, review the release notes and compare the upstream revision with the existing pin. Resolve the target tag from the original upstream repository, for example `git ls-remote https://github.com/actions/checkout.git refs/tags/v6.1.0 'refs/tags/v6.1.0^{}'`. For an annotated tag, take the peeled commit from the `^{}` result. Update the pin and tag comment in every affected workflow and check the new revision in a review PR. See [GitHub Actions security guidance](https://docs.github.com/en/actions/reference/security/secure-use).

Keep workflow permissions read-only. The MTGJSON private draft backup job is the sole job-level write exception. Its private-visibility condition and repeated API checks restrict draft creation and retention to a private repository. It is skipped for the public preview. Pass GitHub expressions as environment variables and quote shell expansions.

Scheduled rules and MTGJSON monitors are separate from PR regression CI. Forge gameplay and runtime download workflows require manual dispatch. Local YAML and Bash checks establish syntax and enforce repository policy. Cite a matching public Actions run before reporting hosted CI or a manual integration run as executed. Historical private runs belong to the scope and source revision stated in their [release record](releases/CASUAL_PRIVATE_BETA_v0.2_2026-11-01.md).
